# Hermes Google Access

A personal OAuth client for [Hermes Agent](https://hermes-agent.nousresearch.com/docs), used on
the account owner's own machine to work with the account owner's own Google data.

**What it does**

- Reads Gmail messages and metadata so they can be summarised and triaged on the owner's machine.
- Creates and updates Google Calendar events when the owner explicitly asks for it.
- Never deletes mail or calendar data.

**Who uses it**

One person: buiquocviet99@gmail.com. The app is not distributed, has no other users, and is not
offered as a service to anyone else.

**How it runs**

Locally, by the owner, on their own computer. There is no server, no hosted backend, and no
third-party data processing.
